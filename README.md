# 阿福记账 (Afu Ledger)

一个自己用的 Android 记账 App，同时作为个人工程能力作品集开源。

## 状态

🚧 极早期：正在用 [spec 驱动流程](.spec/) 对齐需求，尚未进入实现。

## 目标功能

- [ ] 清爽可换肤的界面（二次元风格、圆润控件、支持换图）
- [ ] 资产账户管理（现金 / 银行卡 / 信用卡等）
- [ ] 手动记账 + 分类
- [ ] 定时 / 周期记账
- [ ] 截图记账（OCR 识别支付截图）
- [ ] 无障碍自动后台记账（微信 / 支付宝）
- [ ] 统计与图表
- [ ] 本地优先、数据可导出
