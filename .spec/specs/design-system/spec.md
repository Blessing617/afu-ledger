# design-system

## Purpose

定义阿福记账的视觉语言：清爽、圆润、可个性化，所有页面共用同一套主题与形状约束。

## Requirements

### Requirement: 圆润控件风格
系统 SHALL 在全局使用大圆角与胶囊形控件，形成统一的柔和视觉。

#### Scenario: 主操作按钮为胶囊形
- GIVEN 任意屏幕上的主操作按钮
- WHEN 按钮被渲染
- THEN 其形状为胶囊形（圆角半径等于高度的一半）
- AND 点击水波纹被裁剪在胶囊形状内

#### Scenario: 卡片与输入框圆角统一
- GIVEN 首页卡片与记账页输入框
- WHEN 两者被渲染
- THEN 卡片圆角为 20dp、输入框圆角为 16dp
- AND 两者圆角来自同一份 Shape 定义，修改后全应用同步生效

### Requirement: 主题色切换
系统 SHALL 提供一组预设主题色，用户选择后全应用立即生效并持久保存。

#### Scenario: 切换主题色
- GIVEN 用户停留在设置页
- WHEN 用户从色板中选择「樱花粉」
- THEN 主色、强调色与导航选中态立即变为粉色系
- AND 重启应用后仍保持樱花粉

### Requirement: 背景图换肤
系统 SHALL 允许用户从相册选择一张图片作为主界面背景，并自行调节其「存在感」，同时保证文字始终可读。

可调项 MUST 至少包含：背景可见度、模糊开关、暗色遮罩开关。可见度 MUST 为连续值而不是固定档位。

遮罩只作用于背景层，MUST NOT 降低卡片与文字本身的不透明度。

#### Scenario: 调高背景可见度
- GIVEN 用户已设置自定义背景图，可见度处于默认值
- WHEN 用户把可见度调到最高
- THEN 背景图片清晰、接近原图色彩
- AND 卡片与正文仍保持当前配色可读，不随背景变淡

#### Scenario: 背景与文字对比度不足时自动托底
- GIVEN 用户把可见度调高且关闭暗色遮罩
- WHEN 背景某区域为浅色、正文为深色
- THEN 卡片容器仍保持不透明底色
- AND 正文不在背景图上直接绘制

#### Scenario: 开启模糊
- GIVEN 用户已设置背景图
- WHEN 用户开启「模糊」开关
- THEN 背景图以模糊形式渲染
- AND 调节可见度时模糊程度不跳变

#### Scenario: 恢复默认背景
- GIVEN 用户已设置自定义背景
- WHEN 用户点击「恢复默认」
- THEN 主界面背景回到主题色渐变
- AND 可见度、模糊、遮罩参数一并重置为默认值

#### Scenario: 背景显示参数持久化
- GIVEN 用户调整了可见度与模糊开关
- WHEN 重启应用
- THEN 背景与参数均保持

### Requirement: 深色模式
系统 SHALL 支持跟随系统、强制浅色、强制深色三种模式，并持久保存用户选择。

#### Scenario: 跟随系统
- GIVEN 用户选择「跟随系统」，且系统处于深色模式
- WHEN 应用启动
- THEN 应用以深色配色渲染
- AND 背景图换肤在深色模式下同样保持可读

### Requirement: 页面转场与动效
系统 SHALL 为页面切换、浮层出现与列表变化提供过渡动效，使操作「跟手」而不是硬切。

动效 MUST 满足：

- 底部标签切换使用淡入淡出（不做横向滑动，避免与系统手势冲突）
- 记账页等二级页面从下往上进入、向下退出
- 悬浮窗从底部滑入并淡入，消失时反向
- 列表项增删改位置时使用位移/淡入动画
- 系统开启「移除动画」（开发者选项 / 无障碍减弱动效）时，MUST 退化为无动画而不是变慢

#### Scenario: 切换底部标签
- GIVEN 用户在首页
- WHEN 点击「资产」标签
- THEN 页面以淡入淡出切换，时长不超过 300ms
- AND 不出现横向滑动

#### Scenario: 记账页进入与退出
- GIVEN 用户在首页
- WHEN 点击「记一笔」
- THEN 记账页从屏幕下方滑入
- AND 返回时向下滑出

#### Scenario: 悬浮窗滑入
- GIVEN 识别命中
- WHEN 悬浮窗显示
- THEN 以底部滑入 + 淡入的方式出现，时长不超过 300ms

#### Scenario: 关闭系统动画时的降级
- GIVEN 系统设置中动画缩放被设为 0 或启用了减弱动效
- WHEN 发生页面切换或悬浮窗出现
- THEN 直接切换，不播放动画
- AND 功能行为不变

### Requirement: 应用图标

系统 SHALL 使用「大肥鱼」形象作为自适应图标（adaptive icon），在 HyperOS 桌面、最近任务与设置的应用列表中都正确显示，且前景主体不超出安全区。

图标 MUST 以矢量或高分辨率位图提供，适配圆形、圆角方形、方形三种遮罩。

#### Scenario: 桌面显示自适应图标
- GIVEN 应用已安装
- WHEN 用户在桌面查看图标
- THEN 显示大肥鱼形象而不是系统默认图标

#### Scenario: 不同遮罩下不被裁切
- GIVEN 系统使用圆形遮罩
- WHEN 渲染图标
- THEN 大肥鱼主体完整可见，耳朵/尾巴不被裁切

#### Scenario: 图片未就绪时的降级
- GIVEN 图标前景资源缺失或解析失败
- WHEN 构建 APK
- THEN 构建失败并给出明确错误，而不是产出无图标包
