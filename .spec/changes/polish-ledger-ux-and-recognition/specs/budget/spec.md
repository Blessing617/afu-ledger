# Delta：budget

## MODIFIED Requirements

### Requirement: 预算管理页

系统 SHALL 提供预算管理页，集中展示所有预算并支持增删改。

- 列表 MUST 显示每个预算的名称、周期描述（含本期起止日期）、已用 / 总额度、剩余、状态。
- 新建与编辑 MUST 在同一表单中完成，表单包含：名称、金额、周期类型、月度起始日（仅月度）、自定义起止（仅自定义）、分类多选（可全不选）、预警阈值、启用开关。
- 表单 MUST 使用**底部面板**呈现（与记账面板同一套交互语言），MUST NOT 使用 Material 默认描边输入框
  堆出一列「表单脸」：
  - 金额 MUST 用大字号展示，并配应用内数字键盘（复用记账面板的键盘组件与规则），MUST NOT 弹出系统数字键盘
  - 周期 MUST 用胶囊分段控件；月度起始日、预警阈值 MUST 用步进器或滑块调整，MUST NOT 要求弹键盘输入
  - 分类 MUST 用圆形图标 + 名称的可选格，选中态有明显反馈
  - 底部 MUST 只有一个胶囊形主操作按钮，标题栏 MUST NOT 再放第二个「保存」
  - 关闭方式 MUST 与记账面板一致：下滑、右上角关闭按钮、返回键；MUST NOT 点击遮罩关闭
- **编辑已有预算时，修改金额 MUST 能保存**：
  - 金额输入框预填的文本 MUST 可直接编辑（允许千分位逗号与两位小数），MUST NOT 因为预填格式而让保存按钮永久不可用
  - 修改额度后保存 MUST 写入新值，列表与首页预算卡片 MUST 立即反映新额度
  - 名称、周期、起始日、分类、阈值、启用状态的修改 MUST 同样可保存
- 校验 MUST 阻止：金额为空或 ≤ 0、名称为空、自定义区间结束早于开始、月度起始日不在 1–28。
- 空状态 MUST 给出「怎么开始」的引导，而不是一片空白。
- 删除 MUST 二次确认。

#### Scenario: 新建预算
- GIVEN 用户在预算管理页
- WHEN 用户点击新建并填写名称「餐饮」、金额 1500、周期月度、绑定「餐饮」分类后保存
- THEN 列表出现该预算
- AND 首页卡片随之更新（若它是展示对象）

#### Scenario: 修改已有预算的金额并保存
- GIVEN 已存在预算「本月」，额度 3,000.00 元
- WHEN 用户打开它，把金额改为 3,500 并点击保存
- THEN 保存按钮可用且保存成功
- AND 列表显示额度 `¥3,500.00`
- AND 首页预算卡片的额度同步变为 3,500.00
- AND 其余字段（周期、分类、阈值）保持不变

#### Scenario: 只改启用状态也能保存
- GIVEN 已存在一个启用的预算
- WHEN 用户打开它、关闭「启用」并保存
- THEN 该预算在列表中显示为已停用
- AND 首页不再展示它

#### Scenario: 非法输入被拒绝
- GIVEN 用户在编辑表单
- WHEN 金额留空或填入 0 后尝试保存
- THEN 保存按钮不可用或提示金额必须大于 0
- AND 不会写入非法预算

#### Scenario: 空状态引导
- GIVEN 用户没有任何预算
- WHEN 用户进入预算管理页
- THEN 显示引导文案与「新建预算」入口

#### Scenario: 表单与记一笔同款交互
- GIVEN 用户在预算管理页点击新建
- WHEN 面板出现
- THEN 金额为大字号并可用应用内数字键盘输入
- AND 周期为胶囊分段控件
- AND 不弹起系统键盘
- AND 只有底部一个主操作按钮
