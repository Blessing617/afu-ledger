# 变更：预算管理

## 动机

记账 App 只有「花了多少」，没有「还能花多少」。用户需要给一段时间设一个额度，在主页一眼看到剩余，快超支时被提醒 —— 这是同类开源记账应用的标配（Ivy Wallet 的 `feature/budgets`、Firefly III 的 budgets、Cashew 的预算页），也是阿福记账目前缺的最影响「认真使用」的一环。

## 范围

在范围内：

- 预算实体：名称、金额、周期、分类范围、预警阈值、启用状态
- 周期：月度（起始日可调）、周（ISO 周，周一起）、年度、自定义起止区间
- 维度：不绑分类 = 总预算；绑 1~N 个分类 = 分类预算
- 首页预算卡片：剩余额度、进度条、使用率分档配色与俏皮文案
- 预算管理页：列表、新建、编辑、删除、启用/停用
- 预警：使用率 ≥ 阈值（默认 80%）变橙，≥ 100% 变红并提示超支
- 备份：预算随导出/导入一起走（备份格式 v2，兼容读 v1）

不在范围内：

- 结余结转（rollover）—— 用户明确不要
- 按账户维度限制预算
- 预算的系统通知推送（首版只做界面内的视觉预警）
- 预算与实际收入的关联（比如「收入的 30% 用于餐饮」）

## 方法

新增 `budgets` 表（DB v3，AutoMigration 2→3），周期区间计算放在纯 Kotlin 的 `BudgetPeriod` 里便于单测；已用金额用一条 SQL 聚合（`type = 'EXPENSE'` + 区间 + 可选分类 IN）。首页在「今日卡」下方渲染预算卡片，点击进入预算管理页；设置页「记账」分组加入口。备份格式升级到 v2 并向后兼容读取 v1。
