# Delta：design-system

## MODIFIED Requirements

### Requirement: 系统栏安全区适配
系统 SHALL 在 edge-to-edge 显示下保证页面内容不被状态栏、导航条或手势条遮挡，且系统栏图标明暗跟随当前主题。

内容区 MUST 应用安全区 inset：顶部首个元素 MUST 位于状态栏之下，底部可滚动内容的最后一项 MUST 能滚出导航条区域。

**曲面屏的两侧同样算安全区**：底部导航的文字与图标 MUST 离屏幕左右边缘留出至少 20dp，
MUST NOT 依赖「手势条 inset」—— 曲面屏的弯曲区不在系统 inset 里，但同样会吃掉内容。

浅色主题下状态栏与导航条图标 MUST 为深色，深色主题下 MUST 为浅色。

二级页面整屏覆盖（含底部导航）时 MUST 自己处理安全区，MUST NOT 出现双重留白。
整屏对话框/编辑器覆盖状态栏时 MUST 同时把状态栏图标改成深色（浅色背景）或浅色（深色背景），
MUST NOT 让状态栏文字变成看不清的白字。

#### Scenario: 首页顶部不被状态栏压住
- GIVEN 设备处于 edge-to-edge 显示
- WHEN 用户打开首页
- THEN 今日卡片完整显示在状态栏下方
- AND 状态栏图标为深色，清晰可见

#### Scenario: 二级页不重复留白
- GIVEN 用户进入分类管理
- WHEN 页面出现
- THEN 标题栏紧贴状态栏下方
- AND 没有额外的空白条

#### Scenario: 曲面屏底部文字不被折边吃掉
- GIVEN 设备为曲面屏，底部导航有四个标签
- WHEN 用户查看底部导航
- THEN 最左侧与最右侧标签的文字距屏幕边缘至少 20dp
- AND 文字完整可读，不落在弯曲区

#### Scenario: 整屏编辑器覆盖状态栏时图标可见
- GIVEN 用户打开定时记账的整页编辑器（浅色主题）
- WHEN 编辑器覆盖到状态栏区域
- THEN 状态栏的时间与图标为深色、清晰可见
- AND 状态栏背景与编辑器背景一致，不出现灰色遮罩条
