# 变更：底栏形状对称与点击反馈

## 动机

底部导航改成「中央凹槽 + 圆角」之后，出现了两个问题：

1. **左右不对称**：形状路径从左上角起笔，末尾 `close()` 直接把左下角斜连回起点，
   左上角根本没有圆角 —— 左端是一个斜切角，右端是圆角，一眼就能看出歪。
2. **点击反馈不匹配**：标签的涟漪是矩形水波纹，压在圆润的底栏与圆形选中态上显得突兀。

## 范围

在范围内：

- 底栏形状补左右对称的圆角
- 标签点击涟漪裁成圆角
- 凹槽与按钮同心、留出均匀呼吸缝

不在范围内：

- 底栏配色与图标艺术风格的整体重做（手绘描边图标那一套）
- 其它控件的涟漪

## 方法

`BottomBarShape` 的路径按「左上圆角 → 直线 → 外凸过渡 → 内凹圆弧 → 外凸过渡 → 直线 → 右上圆角 → 右侧 → 底边 → 左侧 → 左上圆角」闭合，两端圆角参数一致。
`TabItem` 的点击区域用 `clip(RoundedCornerShape(18.dp))` 包住，涟漪跟随形状。
