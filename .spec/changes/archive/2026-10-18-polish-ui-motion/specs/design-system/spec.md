# Delta：design-system

## MODIFIED Requirements

### Requirement: 页面转场与动效
系统 SHALL 为页面切换、浮层出现与列表变化提供**符合层级关系**的过渡动效，使操作自然连贯而不是硬切或生硬平移。

动效 MUST 满足：

- **同级切换**（底部标签之间）：使用淡入 + 小幅位移（水平方向不超过屏宽 12%），MUST NOT 整屏平移
- **层级进入**（标签页 → 二级页面）：从下方滑入，并配合淡入；返回时向下退出
- **层级返回**（二级页面 → 标签页）：方向必须与进入时相反
- 缓动 MUST 使用减速曲线或 spring，MUST NOT 线性匀速
- 时长分档统一：同级切换 ≤ 200ms，层级进入 ≤ 260ms
- 系统开启「移除动画」时退化为无动画

#### Scenario: 标签之间切换
- GIVEN 用户在首页
- WHEN 点击「资产」标签
- THEN 新页面以淡入 + 不超过屏宽 12% 的水平位移出现
- AND 旧页面同时淡出
- AND 不出现两页整屏平移的「推卡片」感
- AND 时长不超过 200ms

#### Scenario: 进入二级页面
- GIVEN 用户在记账页（底部标签页）
- WHEN 点击右下角「记一笔」
- THEN 记账表单从屏幕下方滑入
- AND 时长不超过 260ms

#### Scenario: 从二级页面返回
- GIVEN 用户在记账表单
- WHEN 点击返回
- THEN 表单向下滑出
- AND 回到发起它的那个标签页，方向与进入时相反

#### Scenario: 缓动不做匀速
- GIVEN 任意一次转场
- WHEN 观察位移曲线
- THEN 起始快、结束慢（减速），不出现线性匀速移动

#### Scenario: 关闭系统动画
- GIVEN 系统动画缩放为 0 或启用减弱动效
- WHEN 发生任意转场
- THEN 直接切换，不播放动画
- AND 功能行为不变

### Requirement: 背景图换肤
系统 SHALL 允许用户从相册选择一张图片作为主界面背景，并自行调节其「存在感」，同时保证文字可读。

可调项 MUST 至少包含：背景可见度、模糊开关、暗色遮罩开关。可见度 MUST 为连续值而不是固定档位。

**背景图 MUST 以原始分辨率显示，MUST NOT 为了性能而降低解码分辨率。**

遮罩只作用于背景层，MUST NOT 降低卡片与文字本身的不透明度。

#### Scenario: 调高背景可见度
- GIVEN 用户已设置自定义背景图，可见度处于默认值
- WHEN 用户把可见度调到最高
- THEN 背景图片清晰、接近原图色彩
- AND 卡片与正文仍保持当前配色可读，不随背景变淡

#### Scenario: 背景保持原始分辨率
- GIVEN 用户选择了一张高于屏幕分辨率的图片
- WHEN 应用渲染背景
- THEN 背景按原图分辨率解码并显示
- AND 放大查看时不出现因降采样导致的模糊

#### Scenario: 背景与文字对比度不足时自动托底
- GIVEN 用户把可见度调高且关闭暗色遮罩
- WHEN 背景某区域为浅色、正文为深色
- THEN 卡片容器仍保持不透明底色
- AND 正文不在背景图上直接绘制

#### Scenario: 开启模糊
- GIVEN 用户已设置背景图
- WHEN 用户开启「模糊」开关
- THEN 背景图以模糊形式渲染
- AND 调节可见度时模糊程度不跳变

#### Scenario: 恢复默认背景
- GIVEN 用户已设置自定义背景
- WHEN 用户点击「恢复默认」
- THEN 主界面背景回到主题色渐变
- AND 可见度、模糊、遮罩参数一并重置为默认值

#### Scenario: 背景显示参数持久化
- GIVEN 用户调整了可见度与模糊开关
- WHEN 重启应用
- THEN 背景与参数均保持
