# 变更：打磨转场动效与背景图体验

## 动机

上一轮把「响应速度」指标压下去了（p90 8ms、janky 0.04%），但用户实际用起来仍然觉得**不丝滑**。
对照体验更好的同类应用后，问题不在「快不快」，而在**动效是否自然**：

1. **标签切换的横向滑动不自然**：两页同时整屏平移，视觉上像「推卡片」，缺少层级感与节奏。
2. **设置 → 记账 的转场不合理**：一边是底部标签页，一边是二级页面，却用了同一套横向逻辑，方向与层级对不上。
3. **背景图为了性能被降采样到半分辨率**：这是拿画质换性能的妥协，用户明确不接受——**图片分辨率不能改**。

## 范围

在范围内：

- 重新设计标签切换动效（淡入 + 轻微位移/缩放，避免整屏平移）
- 二级页面（记账、分类、设置子页）使用符合层级的纵向转场
- 修正「从标签页进入二级页面」与「从二级页面返回标签页」的方向一致性
- 统一缓动曲线为更自然的 spring / 减速曲线，并统一时长档位
- **背景图恢复原始分辨率**，用其他手段消化合成开销
- 系统「移除动画」时退化为无动画

不在范围内：

- 不改动页面内部布局与信息结构
- 不引入新的页面
- 不做 tab 页面保活（那是另一件事，必要时单独开变更）
- 不降低背景图分辨率（明确禁止）

## 方法

动效部分先定义一套「层级 + 方向」规则，再替换转场实现：标签之间是同级切换，用轻量淡入配合 8~12% 的位移；
进入二级页面是「深入」，用纵向滑入并让背景轻微变暗；返回时反向。
背景图部分保持原分辨率，通过移除/合并全屏遮罩层、把背景绘制收敛为单层并复用硬件层来回收性能，
目标是在原分辨率下把 p90 控制在 12ms 以内。

## 待确认

- 标签切换你更喜欢哪一种：**纯淡入**（最轻，无方向感）还是**淡入 + 8% 横向位移**（有方向感、不整屏推）？
- 二级页面纵深效果要不要加「背景轻微变暗」（提升层级感，但多一层绘制）？
