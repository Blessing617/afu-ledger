# 变更：搭建阿福记账骨架并实现手动记账闭环

## 动机

需要一个自己日常能用的记账 App，同时作为开源工程作品集。当前 `afu-ledger` 仓库只有 README 与 `.spec/` 骨架，没有任何代码。

第一版目标是**能立刻装机使用**的最小闭环：记一笔、看得到、资产余额对得上，并且界面从一开始就具备「圆润 + 可换肤」的视觉基调（后续所有页面都建立在这套设计系统上）。

## 范围

在范围内：

- 可编译、可安装的 Android 工程骨架（Kotlin + Jetpack Compose）
- 设计系统：大圆角与胶囊按钮、主题色切换、深色模式、背景图换肤
- 数据层：Room 数据库（账户、分类、交易三张表）
- 手动记账：新增 / 编辑 / 删除交易，按日期分组展示
- 资产账户：新增 / 编辑 / 归档账户，余额随记账联动

不在范围内（后续变更）：

- 无障碍自动记账、截图 OCR 记账
- 统计图表、预算、周期记账
- 云同步、备份导出
- 多币种、多账本
- 登录、密码锁
- 国际化（第一版仅简体中文）

## 方法

建立单模块 Compose 工程，Room 持久化，ViewModel + StateFlow 驱动 UI。
设计系统以 Material 3 为基础，通过自定义 `Shape`、`ColorScheme` 与背景图容器统一约束，
换肤配置存在 DataStore 中，主界面启动时读取。
交易与账户通过同一 ViewModel 协调，账户余额由「初始余额 + 收入 - 支出」实时计算，不冗余存储。
