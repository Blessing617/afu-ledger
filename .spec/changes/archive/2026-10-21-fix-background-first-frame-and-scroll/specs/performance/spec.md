# Delta：performance

## MODIFIED Requirements

### Requirement: 背景图加载不突现
系统 SHALL 让自定义背景图在**首帧就可见**，并且避免任何黑屏 / 白屏跳变。

实现 MUST 同时满足：

- 图片就绪前 MUST 用**占位缩略图**（≤ 96px 宽）铺满，解码耗时 MUST 在一帧以内；缩略图缺失时才回退到主题底色
- 背景图 MUST 按**屏幕像素尺寸**解码（1:1），MUST NOT 按原始分辨率解码 —— 显示区域只有屏幕大小且用 Crop 铺满，原分辨率解码只会拖慢首帧、抬高合成带宽
- 预加载与界面显示 MUST 共用同一 `memoryCacheKey`，冷启动预热才对界面生效
- 原图就绪后以淡入（≤ 200ms）覆盖占位图，MUST NOT 硬切
- 缩略图 MUST 在「设置背景图」时生成，并在启动时自动补齐缺失的缩略图

#### Scenario: 冷启动首帧就有背景
- GIVEN 用户已设置自定义背景图，且已有占位缩略图
- WHEN 冷启动应用并抓取首帧
- THEN 首帧已经能看到背景图（可以是模糊占位）
- AND 不出现纯色底空窗
- AND 原图在 1.5 秒内淡入覆盖占位图

#### Scenario: 大图不按原始分辨率解码
- GIVEN 用户选择一张 4000×3000 的照片作为背景
- WHEN 冷启动应用
- THEN 解码后的位图尺寸为屏幕像素尺寸（1440×3200 级别）
- AND 冷启动 `TotalTime` ≤ 800ms

#### Scenario: 缩略图缺失时自动补齐
- GIVEN 用户在本版本之前就已设置过背景图（没有缩略图文件）
- WHEN 升级后第一次启动应用
- THEN 启动时自动生成缩略图
- AND 第二次冷启动时首帧即可见背景

## ADDED Requirements

### Requirement: 自定义背景下的滚动不降级
系统 SHALL 在「设置了自定义背景图」的前提下，让首页、明细页、设置页的快速滑动仍满足既有帧预算：超过 32ms 的帧占比 < 5%。

- 背景层 MUST NOT 因为列表滚动而重新组合或重新解码
- 背景图纹理尺寸 MUST 不超过屏幕像素尺寸

#### Scenario: 大背景图 + 长列表滚动
- GIVEN 已设置一张照片背景，明细页有 300 笔跨 20 天的交易
- WHEN 在 release 构建上连续快速滑动 10 次
- THEN `dumpsys gfxinfo` 中 Janky 帧占比 < 5%
- AND 90 分位帧耗时 ≤ 16ms

#### Scenario: 背景层不随滚动重建
- GIVEN 背景图已显示
- WHEN 用户滚动明细页
- THEN 背景层的绘制指令不重新生成（仅参与合成）
