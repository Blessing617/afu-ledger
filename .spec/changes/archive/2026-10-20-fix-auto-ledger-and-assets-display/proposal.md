# 变更：修掉自动记账的重复入账与错备注，并把超大金额显示好

## 动机

今天的真机回馈里暴露四个问题，前两个直接影响账本正确性：

1. **同一笔付款被记了两次。** 支付宝一次 20.00 元的付款依次经过「聚合收款 / 付款成功」和「支付成功」两个页面，两个页面都命中了识别并各弹了一次确认卡片，用户确认后生成两笔 20.00 元支出。根因是去重指纹在「一方有交易单号、一方没有」时必然分裂成两个指纹，而短窗口去重又只按指纹比对。
2. **备注写成了页面按钮文字。** 今天 4 笔自动记账的备注分别是「回首页 返回商家」「返回 按钮」「返回 按钮 完成」（还有一笔为空），真正的商户名（如「杭州深度求索」）一个都没取到。根因是商户候选按「视觉行整行文本」取，而同一行上的两个按钮被拼成一行；按钮/操作文案也不在噪声词表里。
3. **总资产显示不全。** 净资产 34sp 大字号不换行约束缺位、总资产小卡 `maxLines = 1` 直接裁切，金额到 99 万亿量级就会被截断或折行成两行。
4. **设置页的自动记账区块是一整面常驻说明。** 总开关关着时，无障碍状态、默认账户、默认分类、OCR、识别日志全部照样铺开；用户要的是「开关打开后才展开下面的设置」。
5. **无障碍状态刷新滞后。** 在系统设置里开启服务后回到应用，设置页可能仍显示「未开启 / 去打开」，要再切一次页面才变绿。

## 范围

在范围内：

- 自动记账的跨页面去重（同一笔付款在两个页面各命中一次时只记一次）
- 商户名（备注）提取规则：只取商户实体，不取按钮/操作文案；取不到就留空
- 资产页净资产、总资产、总负债的金额格式化：大额自动缩写单位，可展开完整数字
- 设置页自动记账区块改为「总开关 → 展开详情」的可折叠结构
- 设置页无障碍授权状态的实时刷新

不在范围内：

- 重写识别通道、OCR 模型、页面判定规则（本次只动去重、商户提取与展示）
- 定时/周期记账（单独变更 `add-scheduled-ledger`）
- 已经入账的重复数据清理（用户要求先不动，修好后自行处理）
- 云端同步、报表口径变化

## 方法

去重从「单指纹比较」升级为「会话级比较」：同一包名、同金额、同方向的命中在短窗口内视为同一笔，即使两边的交易单号一个有、一个没有；只有两次命中都解析出**不同且非空**的单号时才认定是两笔。商户提取改为「先按 cell 取候选、再用更强的噪声词与按钮文案排除、优先商户字段」，整行拼接文本不再直接当商户。金额格式化新增紧凑单位函数，资产卡在超长时切换为紧凑模式并支持点按展开。设置页把详情包进 `AnimatedVisibility`，无障碍状态改为监听 `AccessibilityManager` 变化 + 前台短时复查。
