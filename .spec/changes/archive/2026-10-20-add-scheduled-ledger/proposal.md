# 变更：加入定时记账（周期自动入账）

## 动机

房租、话费、订阅、工资、定投这类账目每月都在同一时间重复发生，手动一笔笔补录既烦又容易漏。
主流记账产品都有对应能力，但各家的做法有分歧：

- **钱迹「周期记账」**（会员功能）：为周期性收支 / 转账 / 还款设置一次规则，到点**自动生成账单**；
  支持每天 / 每周 / 每月 / 每年 / 每 n 天周月年，支持固定期数或永不结束；
  修改只对后续账单生效，已生成账单可当普通账单二次编辑；
  规则依赖的账户 / 账本 / 分类被删除时任务自动失效并标记结束。
  （来源：[钱迹用户指南 · 周期记账](https://docs.qianjiapp.com/vip/vip_repeat_task.html)）
- **MoneyWiz**：把周期交易作为 *Scheduled Transactions*，先进入「即将发生」清单，用户确认后才落账
  （来源：[MoneyWiz](https://www.wiz.money/)、[少数派：用 MoneyWiz 搭建记账系统](https://sspai.com/post/77618)）。
- **iCost「周期入账」**：同样到点自动生成；当天创建的规则默认「同一时刻」执行，可在设置里自定义时分；
  改规则只影响后续账单。（来源：[iCost 帮助文档](https://help.icostapp.com/guide/fast/loop.html)）
- **随手记「周期账」**：唯一同时提供两种到期行为的国内产品 —— 勾「自动记账」到点直接生成，
  不勾则到期提醒、用户点「入账」才生成；有「激活状态」可关停（≈暂停）。
  （2016 年教程，规则可能已变，见调研报告）
- **YNAB / Actual Budget**：到期**不自动入账**，先加粗待批准；Actual 的自动入账是显式开关，
  还能「Skip Scheduled Date」跳过某一次；两者的「每月 31 日」处理不同（YNAB 顺延到短月末日，
  Actual 会跳过长月之外的一些月份）。
- **鲨鱼记账**、**Money Manager**、**MoneyWiz** 的字段级细节未能证实，调研报告里逐条标注了。

完整调研（含 13 条来源链接、Android 调度约束、幂等设计）：工作区根目录
[记账App定时记账功能调研报告.md](../../../记账App定时记账功能调研报告.md)。

与调研建议的三处**有意分歧**（都按本项目用户的明确选择）：

1. **默认到期行为 = 自动入账**（调研建议默认待确认）。用户的诉求是「定时扣除」，且可选单条改为提醒确认。
2. **错过时补记全部期次**（调研建议默认只补最近一期 + 询问）。用户要求「开机后补记所有错过的」。
3. **「每月 31 日」收敛到当月最后一天**（与 YNAB 一致），并 MUST 在 UI 上写成一句话说明。


用户在本项目的需求是「定时扣除指定账户、指定类型的账目」，与钱迹的语义一致；
但担心规则设错后悄悄扣账，所以本次取两者之长：**默认自动入账，单条规则可切换为「先提醒、我确认」**。

## 范围

在范围内：

- 定时记账规则（新建 / 编辑 / 暂停 / 恢复 / 删除）与规则列表
- 周期计算：每天、每周指定星期、每月指定日、每年指定月日、每 N 天 / 周 / 月 / 年
- 到期自动入账，或按规则改为「先生成待确认、用户确认后入账」
- 错过期次的补记（全部补、带「补记」标记、幂等、有上限）
- Android 侧调度：闹钟 + 每日兜底任务 + 开机重排 + 打开应用时补算
- 与账户 / 分类的联动（失效时暂停而不是静默失败）
- 规则生成账单的来源标记（明细可见、可按规则汇总）

不在范围内：

- 转账、还款、分期（本次只做单账户的收入 / 支出；跨账户转账需要另一套领域模型）
- 工作日 / 节假日感知（如「每月最后一个工作日」）
- 多币种、账本、共享账本
- 云端同步与跨设备一致
- 预算与提醒推送（除提醒模式的一次性通知）

## 方法

新增一张 `schedule_rules` 表与一个纯函数 `ScheduleCalculator`（负责把所有周期类型折算成「计划时刻序列」，
月末收敛、时区、结束条件都在这里，便于单测）。执行侧是一个 `RunDueSchedulesUseCase`：
以「规则 + 期次计划时刻」为幂等键（唯一索引兜底），到期就写交易，`occurredAt` 用计划时刻；
错过的期次一次补齐并打「补记」标记。

调度不用 WorkManager 承担准时性（它最小 15 分钟且受 Doze 影响），而是用 `AlarmManager`
为最近一个期次排闹钟：有精确闹钟权限就 `setExactAndAllowWhileIdle`，没有就退化为
`setAndAllowWhileIdle` / `setWindow`（允许几分钟到更久的延迟，记账场景可接受）。
另有每日 `WorkManager` 兜底、开机广播重排、应用回到前台立即补算三条冗余，保证「一定会被记上」。
不申请任何网络权限。
