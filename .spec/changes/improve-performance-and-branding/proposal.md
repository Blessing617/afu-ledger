# 变更：提升交互性能与品牌外观

## 动机

v0.3.0 功能已经够用，但日常体感不佳，且缺少辨识度：

1. **卡顿与弹窗慢**。自动记账的确认悬浮窗从识别完成到可见有明显延迟；主界面滚动与切换不够跟手。
2. **背景图「淡淡的」**。用户设置了自定义背景，但遮罩写死 `alpha = 0.88`，图片几乎看不出来，也没有任何可调项。
3. **没有应用图标**。Manifest 未配置 `android:icon`，桌面显示的是系统默认图标。

## 范围

在范围内：

- 交互响应预算：冷启动、悬浮窗出现、列表滚动三项给出明确数值并实测达标
- 悬浮窗改为预热复用，消除每次弹出的 Compose 初始化开销
- 首帧主题正确：冷启动即使用已保存的主题与背景，不出现默认紫色闪变
- 背景图可调：可见度（不透明度）、模糊开关、暗色遮罩开关
- 背景图加载不突现：启动预加载 + 淡入兜底
- 页面转场与动效：底部标签淡入淡出、二级页面纵向滑入、悬浮窗滑入、列表项位移动画
- 应用图标：大肥鱼形象的自适应图标（adaptive icon）

不在范围内：

- 自动记账的保活（单独变更 `keep-auto-ledger-alive-on-hyperos`）
- 新增业务功能（统计图表、预算、多币种等）
- 引入网络能力、云端或分析 SDK
- 更换 UI 框架（继续 Compose）
- Baseline Profile / R8 全量优化（收益需单独评估，本次不做）

## 方法

性能部分先测量再改：用 `am start -W`、`logcat` 时间戳与帧统计定位瓶颈，按「悬浮窗预热 → 首帧主题同步读取 → 背景层绘制隔离」的顺序逐项消除。
外观部分给 `ThemeSettings` 增加背景显示参数，把遮罩从固定值改为可调，并用矢量资源绘制自适应图标。
图标素材优先由用户提供位图；若未提供，则用 VectorDrawable 绘制一版可替换的占位形象。

## 已确认的实施口径

- **图标素材**：参考本机 `maid-atelier` 皮肤的 Q 版风格（深蓝发色、鲸鱼尾、泡泡、柔和渐变），
  用 VectorDrawable 绘制一版**简约鲸鱼娘标识**（不做精细插画，保证小尺寸可辨识），后续可由用户替换为精细插画。
  不直接使用该皮肤的任何美术资源（避免版权问题）。
- **背景显示参数**：连续滑块（可见度 0–100%），另加模糊与暗色遮罩两个开关。
- **常驻通知**：接受。低优先级、无声、不弹横幅；用于变更 B 的前台服务保活。
